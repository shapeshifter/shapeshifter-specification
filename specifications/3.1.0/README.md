# Shapeshifter Specification 3.1.0

This directory preserves the XSD snapshot defined by the `V3.1.0` Git tag.

Source tag: [`V3.1.0`](https://github.com/shapeshifter/shapeshifter-specification/tree/V3.1.0) at commit `3078c25a067c641dacd38ae8bde1ba4b4fe48413`.

The `docs/` Markdown and image snapshot is from [commit `92ef001`](https://github.com/shapeshifter/shapeshifter-specification/commit/92ef001b79c6312403e4e463bcbc827c14f5a389), the last documentation state before the `V3.1.0` release tag. The release tag's branch does not contain the Markdown conversion.

`docs/versions.md` is a shared migration index added after the historical snapshot to support the version selector and artifact downloads.

The original XSD filenames, schema references, Markdown paths, and image references are retained. Do not edit this snapshot; make specification changes in the development sources and publish them as a new version.
