# Shapeshifter Specification 3.0.0

This directory preserves the XSD snapshot defined by the `V3.0.0` Git tag.

Source tag: [`V3.0.0`](https://github.com/shapeshifter/shapeshifter-specification/tree/V3.0.0) at commit `2b2f8f394eeab7a47f14e31593bd6634f37621bc`.

The `docs/` Markdown and image snapshot is from [commit `24da5e2`](https://github.com/shapeshifter/shapeshifter-specification/commit/24da5e2d8443108a23aaceca8a8215330fb0c65b), the first complete reviewed Markdown conversion. The Git tag predates that conversion; this documentation snapshot represents the v3.0.0 specification, not files present in the tag tree.

`docs/versions.md` is a shared migration index added after the historical snapshot to support the version selector and artifact downloads.

The original XSD filenames, schema references, Markdown paths, and image references are retained. Do not edit this snapshot; make specification changes in the development sources and publish them as a new version.
